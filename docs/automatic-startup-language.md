# 自动启动与语言（2026-10-19）

登录后由 ChatCoordinator 串行协调启动，好友页复用同一好友目录，不再各自重复拉取。密码验证先取得 login_ticket，验证已有设备或注册新设备取得正式 Token 后才发布登录状态。登录后的默认启动顺序：好友目录 → 首批/已用尽本地 OPK 的补充 → WebSocket → 离线信封/ACK → 已持久化待发包重试 → 好友及本人其他设备的会话材料准备。已有设备不重新注册；会话存在或材料已缓存时不重复消耗 prekey。真正的双棘轮会话仍在首消息加密/认证解密时建立，不把领取 OPK 误记为已建立会话。

注册/上传/领取结果不确定时保持原有保护，不盲目重复远程副作用；设备撤销、证书错误及其他需要用户处理的问题仍显示。某个好友没有 bundle/OPK 不阻断其他好友的准备，发送时会给出具体错误。手动刷新好友或接受好友申请后刷新目录并准备新增设备。

普通网络故障不直接显示“连接丢失”，在前台按 1/2/4/8/16/30 秒退避自动重连。完成同步与准备后重置退避；重连补拉持久化游标并重试原始待发密文，不重新加密。服务端已明确拒绝的业务包不无限重发。退出/后台/设备撤销停止重连。回前台继续恢复；这不是 APNs 或 iOS 后台常驻连接。

登录操作和好友目录拉取使用独立的非 key UIWindow，在弹出页面之上展示转圈状态。好友目录请求完成或失败就关闭提示，不等待后续设备准备、握手、消息同步或重连退避；后台重连仅在好友页显示轻量状态。提示不拦截触摸，不抢键盘焦点，弱网时仍可查看已有消息、切换语言或退出。诊断页面仍保留原始连接日志用于排查。

登录页及“我的”提供“语言 / Language”：简体中文和 English。选择保存到本机，立即更新 SwiftUI locale 和顶层提示，不重建连接或清空输入。主界面、常用状态和提示使用 Localizable.xcstrings；用户正文、姓名、公钥、原始服务端错误及开发日志不作机器翻译。

验证覆盖网络故障分类、有限退避、打包后的中英文资源，以及实际 UI 中英文切换和重启后的语言保留。真实服务器多设备、长时间弱网及真机耗时仍需联调。
